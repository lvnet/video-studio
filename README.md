# AI 短剧工坊 · video-studio

> 人人都能搞创作，不受硬件、算力限制。

一个开源的 AI 短剧生产平台。把从一句创意到成片的完整链路标准化、自动化，让创作不再被显卡和算力门槛卡住。

## 为什么做

影视级 AI 制作的能力已经具备，但工具链是碎的：提示词靠手搓、角色一致性靠运气、失败重来靠人盯、算力和模型 API 各说各话。这个项目要做的，是把这些"脏活"沉淀成可复用的流程资产，让普通人也能稳定地出片。

壁垒在流程资产（权威提示词 Schema、资产版本锁定、最小失败码表、累计成本闸门），不在模型 API 本身。

## 架构：三层

```
┌─────────────────────────────────────────┐
│  创作层   创意 → 剧本 → 分镜 → 素材 → 成片   │
├─────────────────────────────────────────┤
│  控制面   任务编排 / 状态机 / 成本闸门 / 资产版本 │
├─────────────────────────────────────────┤
│  算力适配层  cloud_api │ local_comfyui │ cloud_gpu │
└─────────────────────────────────────────┘
```

算力适配层用统一接口（`GenRequest` → `Backend`）封装三种后端，创作层和控制面不关心底层跑在哪——本地显卡、云 API、云 GPU 可随时切换。注意区分算力层的 `GenRequest`（发给后端的请求）与控制面的 `Task`（持久化任务记录），详见 [ARCHITECTURE.md](ARCHITECTURE.md)。

当前持久化用本地 JSON（单机自用），无事务/无并发锁；多用户多机场景需迁移到 PostgreSQL，迁移路径见 ARCHITECTURE.md。

## 八步制作链

创意 → 剧本 → 角色设定 → 分镜 → 关键帧 → 动画/视频 → 配音/字幕 → 合成成片。

每一步的产物都是带版本的 Artifact，失败可定位、可重试、可续跑。

## 功能清单（当前已实现）

核心流程资产已全部落地，**不依赖任何外部算力即可运行与测试**：

| 模块 | 已实现能力 |
|---|---|
| 项目与剧本 | 项目/剧集/镜头数据模型、txt/JSON/Markdown 剧本导入与自动拆镜、缺字段高亮 |
| 提示词工程 | 权威 H3 三段式 + R2V 六段式包装、`(S1)/(S2)↔voice_id` 绑定（含对白且支持音频才强制）、规则集版本化与热加载 |
| 参考资产 | 资产状态表、人工批准硬门槛、来源声明、`asset_version` 确定性锁定 |
| 控制面 | 任务状态机、租约/幂等/失败重派（3 次进死信）、累计成本闸门、完整命名空间失败码表 + 中文诊断 |
| 后期成片 | 裁头杂音、拼接清单、SRT 字幕、片尾 CTA、后端无关升清抽象 |
| 算力适配层 | 统一 Backend 接口、注册表与切换；三种后端接口**已做实**（ComfyUI 全套 HTTP API / 云 API / 云 GPU Agent 协议），**默认内存桩、零外连、零成本、零版权风险** |
| 合规 | 提示词版权守卫（抗绕过归一化）、内容安全分级过滤、append-only 审计日志 + 哈希链、素材来源检查、LICENSE 边界 |
| 工作台 | 零依赖本地 Web 工作台，八步环节可视化操作 + 控制/合规页 + **算力管理页**（见下） |

**算力接口已做实，真实调用需用户自备**：三种后端的请求构造/响应解析/错误归一/产物契约全部实现并测透，可用 `FakeHttpClient` 验证真实协议；但默认 `dry_run=True` 走内存桩，不产生任何真实请求或费用。要接真实算力：设 `VS_COMPUTE_DRY_RUN=0`、配置端点（如 `VS_COMFYUI_URL`）与密钥引用（如 `credentials_ref` 指向的环境变量名），密钥绝不明文入库或下发浏览器。本平台不下载/打包任何模型权重。

**明确后置（未接真实资源）**：H3/LLM 等外部 API 的真实调用、ComfyUI/云 GPU 的真实机器调度、数据库/Redis 多机部署——接口就绪，资源由用户自备。

## Web 工作台（本地零依赖）

一条命令启动，浏览器打开即可用；无需 Node、无需 npm、无需数据库：

```bash
python start.py            # 默认 http://127.0.0.1:8765，自动开浏览器
python start.py --port 9000 --no-browser
```

- 首次使用点右上角「载入示例」，一键生成多集原创示例（3 集剧本、拆镜、角色性别识别、资产库、批准态提示词、桩任务、合成记录）。
- 左侧信息架构对齐专业 production 流程：
  - **制作管理**：剧本 / 分集管理（多集目录）、**八步制作流程**、资产库、合成完整视频。
  - **配置**：视频生成配置（H3 R2V + SeedVR2 模型参数面板，仅存配置不打包权重）、编辑专家（可编辑 prompt 专家库）。
  - **控制与合规**：成本闸门、合规审计。
- **八步制作流程**（方案定稿，每步功能点均为真实可调用接口，非占位）：
  1. **创建项目**：片名 / 画幅 / 风格 / 集数 / 单集时长 / 预算 → 生成剧集骨架（幂等）。
  2. **剧本**：梗概生成大纲 / 整本原稿自动分集 / AI 改写（前后对照）/ 版本链 + 人工确认。
  3. **拆镜**：按场景 / 动作 / 对白拆镜，缺字段高亮，镜头可编辑、可重跑。
  4. **参考资产**：登记资产 + 来源声明、人工批准硬门槛、镜头绑定已批准资产并锁定版本。
  5. **提示词**：H3 三段式 / R2V 六段式扩写（合规前置）、批量扩写、批准评分、清理未批准版本。
  6. **提交生成**：累计成本闸门校验、批量建任务（链式锁 / 成片模式 / 全选）、一键停止。
  7. **监控挑片**：每段 2–4 候选、挑片采用（唯一真源）、失败码诊断、一键重试。
  8. **精修成片**：裁头 + 拼接 + SRT 字幕 + 片尾 CTA + 升清策略的装配计划、成片导出记录。
- 支持 URL 深链：`#workflow/step=0..7` 可直接打开八步流程的指定步骤。
- 后端为 `web/api_server.py`（标准库 `http.server`，67 条路由），前端为纯 HTML/CSS/JS，全部零第三方依赖、离线可用。
- 「算力管理」页：三种后端全景（模式/健康/能力/配置）、一键切换、接口自检（内存桩跑通 submit→poll→fetch）、ComfyUI 工作流预览。
- 数据存 `workspace_data/`（可用环境变量 `VS_DATA_DIR` 改路径），不入库。
- API 集成测试：`python -m unittest tests.test_api tests.test_workbench_api tests.test_workflow_api`。

## 快速开始

无需安装任何第三方依赖，Python 3.11+ 即可：

```bash
# 一键环境自检（逐项给修复建议）
python doctor.py

# 跑全部测试（标准库 unittest，零第三方依赖）
python run_tests.py

# API 集成测试（起真实 HTTP 服务走完整链路）
python -m unittest tests.test_api

# 端到端演示：剧本→拆镜→提示词→合规→成本闸门→调度→成片计划（零外部算力）
python examples/end_to_end.py

# 启动 Web 工作台（浏览器可视化操作）
python start.py
```

ffmpeg 仅成片导出时需要；缺失不影响核心流程（自检会标为可选）。
